# 手动选择任务技能

技能是可复用的任务流程说明，采用 [Agent Skills 的 SKILL.md 格式](https://agentskills.io/specification)。本阶段支持宿主登记、网页手动选择、正文加载及每轮快照；CLI 从运行配置的 skills 读取所选名称。技能不会增加工具权限，也不能修改预算或宿主验收。

## 登记与使用

在运行配置文件中登记技能集合根目录。每个根目录直接包含若干技能子目录，子目录名须与 frontmatter 的 name 一致：

    examples/skills/
      code-delivery/
        SKILL.md

运行配置示例（位于任意 TOML 表之前）：

    skill_roots = ["examples/skills"]
    skills = ["code-delivery"]

相对路径以这份运行配置文件所在目录为基准。网页启动时仍通过 --config 指定运行配置，不需要在 web.example.toml 重复登记。仓库的 harness.example.toml 默认登记示例集合，初始没有选中技能。

SKILL.md 必须为完整 UTF-8 文件，以 YAML frontmatter 开始，例如：

    ---
    name: code-delivery
    description: 小型代码修改的交付流程
    ---

    先阅读项目约定，完成必要修改，并如实说明实际测试结果。

name 为 1—64 字符的小写字母、数字及单连字符，首尾不能为连字符；description 为 1—1024 字符非空说明。支持规范中的 license、compatibility、metadata 和 allowed-tools 元数据。allowed-tools 仅保留在原文中，不向宿主申请权限；正文提到的脚本和附属资料不会自动执行或加载。集合目录及路径中的链接、重解析点和特殊文件会被拒绝。

网页操作：

1. 在新任务表单的“任务技能”中选择所需流程，再提交任务。损坏或名称冲突的技能禁用并说明原因；没有选择仍可正常运行。
2. 完成后在会话输入区展开“下一轮技能”。默认沿用最新一轮的选择，可以更换或全部取消；选择只影响下一次发送。
3. 在详情“上下文”查看本轮真正加载的名称、用途、来源、字节数、SHA-256 及完整正文。页面读取本轮持久事件，不用当前磁盘内容替代旧快照。

发送结果未知时，重试沿用原请求及原技能选择；新编辑的选择不改变已发送请求。刷新和读取历史不会自动执行技能或发送任务。

## 执行与持久化

启动时按名称在当前宿主登记的集合中定位技能，完整读取一次。SKILL.md 的原始 UTF-8 字节决定指纹和大小，包含 frontmatter；本轮后续调用使用冻结正文。新一轮重新读取当前版本，旧轮正文及指纹保持不变。

宿主 system 规则之后的一条固定 user 前缀合并项目 AGENTS.md 和所选技能，然后接入已核验的对话历史与新任务。沿用既有会话前缀协议，旧轮项目/技能前缀不会再次当作用户历史继承。技能是流程指导；实际用户要求、宿主权限、预算及独立验收仍由原机制控制。

context_prepared 事件新增 skills 快照数组和 skill_error 错误对象；RunView.context 从该事件聚合。旧记录缺省为空数组和空错误。快照包含 name、description、source、content、sha256、size_bytes；错误包含 name、code、message。GET /api/options 的 skills 提供目录元数据和可用性；浏览器的 config 仅接受 skills 名称数组，不能提供根路径或正文。

技能正文参加每轮整体 messages/tools 输入预算，固定前缀在分层压缩中受到保护；不能通过压缩删掉已选技能来放行超限请求。若固定内容本身超限，模型不会实际调用。选中技能读取失败时，该运行保存 failed 及 skill_* 原因，context.skill_error 给出说明，模型与工具调用均为零。失败轮仍保存可信历史与本轮要求，可以清空或更换技能后继续同一会话。

## 当前边界

- 最多登记 8 个根目录，总计扫描 256 个直接目录项，不递归搜索。
- 每轮最多选择 8 个技能；单个文件最多 64 KiB，所选原始字节合计最多 256 KiB。整体模型输入预算仍可能更严格。
- 同名跨根目录视为冲突，不按目录顺序静默覆盖；无效未选技能不阻塞正常选择。
- 本阶段不做自动匹配、模型自主激活、附属脚本执行、技能上传编辑或插件市场。正文按人工选择加载，不宣称完整实现所有 Agent Skills 生态能力。
- 自动化及页面联动采用确定性离线模型验证真实加载、工具、Git 与测试机制，不证明某个技能能提升真实模型质量。验收证据见 WEB_CONSOLE.md。
