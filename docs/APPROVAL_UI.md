# 审批界面重构（2026-11-03）

本轮按用户批准的 Plan 统一计划、动作与成果采纳的审阅层级。参考 [Cline 文件差异审阅](https://marketplace.visualstudio.com/items?itemName=saoudrizwan.claude-dev) 和 [VS Code 工具请求审批](https://code.visualstudio.com/docs/agents/run/approvals)，沿用工作台现有主题变量和 Ant Design，不引入新的 UI 框架。

## 展示与交互

- 统一标题、真实状态、目标、证据阅读区和决定区；策略与历史按需展开。
- 文件修改直接显示原文与新文、增删标记及双侧行号。局部编辑明确标为替换片段；无法读取原文本时明确提示，不能伪造差异。超过1200行的对比回退完整原文，避免海量DOM且不丢弃内容。
- 命令优先展示可读参数，空参数、引号和控制字符保留边界；完整原始参数始终可展开。格式化结果仅供阅读，不成为执行字符串或审批载荷。
- 成果采纳保留目标目录、分支、固定版本和完整影响文件，候选检查与写回分别确认；固定集成补丁复用现有解析器显示行号和增删色。
- 计划与动作审批的长正文在有界容器内部滚动，标题和决定区保留。手机按钮触控高度40像素；浅深色及减少动画偏好沿用现有主题。
- 历史只读，已批准排队、过期、失效和执行结果继续来自后端，不将批准显示为执行成功。
- 同轮细调输入区模式入口：工作模式和三种权限统一为无边框、图标与文字的紧凑选择器，去除112/140像素最小宽度。桌面实测“自动”约63像素、“工作区编辑”约99像素，高28像素；手机高32像素。行为说明只在248像素下拉菜单展示，长说明换行；新建任务和续聊共用，不改变选择语义或触发执行。

后端未修改：现有API、动作指纹、请求编号、单次批准、预算接续及权限边界保持。验证通过真实HTTP和独立夹具核对前后端链路，而非只验证静态样式。
