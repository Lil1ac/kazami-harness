# 检查点恢复

本能力对应 [PRD 第10项](PRD.md#3-用户故事与完整功能范围)，用于中断后继续同一个用户要求。与任务结束后发送新要求的[多轮交互](MULTITURN_TASKS.md)分开维护；当前首版范围为宿主登记的 Git 代码任务。

## 1. 用户流程

1. 在网页提交代码任务，系统在完整工具批次结束后的安全边界保存检查点。
2. 服务中断后重新启动，打开原会话，在任务详情查看最近检查点与恢复条件。
3. 点击恢复后，服务核验记录、工作树、代码和预算，再从保存补丁派生新的独立工作树。
4. 新尝试继续原要求；此前已经完成的工具结果进入历史，宿主不重放这些工具。
5. 完成后重新执行宿主测试、生成代码差异，并等待用户审阅。

刷新页面、读取历史和 SSE 重连只读取记录，不自动开始恢复。恢复是同一条用户要求下的新执行尝试；用户消息不重复出现，旧尝试仍可查看。

## 2. 检查点与运行记录

检查点独立保存封存时的完整配对消息、项目指令、配置、压缩投影及证据来源、累计预算、事件前缀校验信息和 Git 补丁/代码摘要。运行中检查点与收尾审阅补丁分别保存，后续执行不能覆盖已发布的恢复依据。

每次恢复建立新的 Run，保存以下关联：

| 字段 | 语义 |
| --- | --- |
| session_id | 沿用原会话 |
| turn_index | 沿用当前用户要求的轮次 |
| attempt_index | 同一要求的执行尝试序号，恢复时递增 |
| resume_source.source_run_id | 直接来源尝试 |
| resume_source.checkpoint_id | 来源尝试的封存检查点 |
| resume_source.checkpoint_sha256 | 固定检查点正文摘要 |

原运行的清单、JSONL、结果和已保存补丁保持原样。新运行只能使用核验后的封存消息与证据；普通追加要求对可信终态的检查不会因此放宽。

## 3. 可恢复条件

首版只支持最新执行尝试，且必须存在完整、可信、属于该任务的检查点。提交时重新核验工作树归属、Git 基线、代码内容与保存补丁，不仅依赖页面先前显示的状态。

以下情况阻止自动恢复，并显示受控原因：

- 工具已开始但执行结果无法确认，或检查点之后出现不能确认的副作用。
- 关联进程清理未知或不完整。
- 工作树身份或内容变化、代码已丢弃、记录或证据损坏。
- 运行已经完成，或已进入宿主验收等不受支持的恢复阶段。
- 同一要求的累计预算耗尽，或会话存在未确认的恢复准备。
- 普通文件工作区、没有检查点的旧记录及首版未覆盖的执行边界。

命令工作目录约束仍不是容器沙箱。首版恢复不推断任意外部写入是否幂等，也不尝试自动重放状态不明的命令。

## 4. 预算

RunResult 原有 model_turns、http_attempts、tool_calls 和 usage 表示本次尝试；resume_budget 表示本次开始前，同一用户要求恢复链已经消耗的累计预算。页面同时展示本次与累计值；恢复不静默清零模型、工具和摘要额度。

active_duration_seconds 以秒记录本次主动执行时长；恢复链相加约束总运行时长，停机等待不计入。已开始但没有获得响应的模型请求照常占请求额度，用量标记为不完整，不能将未知费用当作零。

摘要仍由统一模型请求入口计数，原始轨迹与压缩来源保留。上下文回读只授权封存证据，不因恢复而开放整个中断运行或其他会话的记录。

## 5. HTTP 与幂等

GET /api/runs/{id}/recovery 返回支持状态、静态可恢复条件、最近检查点、阻断原因和忙碌运行编号；GET 不执行工具，不重新捕获代码。实际恢复提交时进行强核验。

POST /api/runs/{id}/resumes 接收 request_id 和 checkpoint_id，成功以202返回新尝试的 RunView。浏览器不提供新的宿主路径、任意验收命令或新的用户任务。

请求意图在创建工作树前持久化，在启动 Runner 前固定新尝试关系。相同编号与相同载荷返回原请求结果；相同编号不同载荷拒绝。网络响应丢失后沿用原编号确认，重启后状态不明的准备不会自动再次执行。

## 6. 验证

确定性测试覆盖检查点完整性、来源、工具边界、预算累计、会话尝试关系、幂等和重启读取。浏览器辅助服务位于 tests/helpers/serve_checkpoint_fixture.py，使用独立真实 Git 项目、实际工具与宿主测试，模型响应固定。

浏览器验收需要从页面提交、在模型等待阶段中断服务、重启、点击恢复，并核对旧命令只执行一次、代码保留、宿主测试与审阅结果。固定模型仅验证执行机制；实际证据与最终通过数量统一记录在[控制台说明](WEB_CONSOLE.md)。
