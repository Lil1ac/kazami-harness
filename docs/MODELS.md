# 模型供应商与角色配置

| 供应商 | 默认模型 | CLI / 独立 Web 凭据 | 请求地址 |
| --- | --- | --- | --- |
| DeepSeek | `deepseek-flash` | `DEEPSEEK_API_KEY` | DeepSeek 官方接口 |
| Qwen | `qwen-plus` | `DASHSCOPE_API_KEY` | 阿里云百炼北京地域公共接口 |

桌面用户在运行配置页分别保存密钥。Electron 使用系统加密按供应商分区，服务端公开的是本地配置状态。首次请求才验证远端认证。升级前保存过单一模型密钥的桌面用户需在设置页重新保存 DeepSeek 密钥。旧版运行清单使用旧版应用查看。

新建对话的模型选择显示当前配置及另一供应商默认模型。运行配置页可指定主模型名称和探索、审阅的独立供应商及模型。没有角色覆盖时使用父会话模型，开发角色也继承父会话。独立角色的任务上下文和工具结果发送给该角色配置的供应商。普通续轮、审批接续和队列沿用已固定的配置。选择另一组模型配置时新建会话。自动化规则的审核及启动核验包含模型配置，设置变动导致授权失效时应重新审核。

独立 Web 和 CLI 可在宿主 TOML 配置供应商及角色。

```toml
provider = "deepseek"
requested_model = "deepseek-flash"

[role_models.review]
provider = "qwen"
requested_model = "qwen-plus"
```

CLI 的 `--provider` 和 `--model` 可覆盖主模型。切换供应商时省略 `--model` 会使用新供应商的默认模型。Qwen 使用支持流式文本和函数工具的百炼模型。两家适配器共用超时、有限重试及流式校验，凭据仅发送到内置官方 HTTPS 地址。

## 自定义服务商

桌面打开「运行配置 → 自定义服务商 → 新增服务商」，输入名称、Base URL 和默认模型 ID。远程连接选择 API Key，保存定义后在该服务商下保存密钥。本机回环连接可选择「本机免密」。点「测试连接」可分别查看连接、认证、流式正文和工具调用结果。探测使用固定合成消息，并校验模拟工具参数。项目文件、会话和真实工具均不参与探测。

独立 Web 和 CLI 在运行 TOML 中登记。服务商 ID 以 `custom-` 开头。远程连接填写该服务商专属的 `api_key_env`，实际密钥存于宿主环境。下面是本机免密配置。

```toml
[custom_providers.custom-local]
name = "本机兼容服务"
base_url = "http://127.0.0.1:11434/v1"
default_model = "your-local-model"
auth = "none"
enabled = true
```

CLI 可用 `--provider custom-local`。新建会话和探索、审阅角色可以直接选择登记的服务商，设置页支持覆盖模型 ID。接口向 Base URL 追加 `/chat/completions`，要求 OpenAI Chat Completions 风格的 SSE 正文与工具调用。用量取服务实际返回值。远程地址使用 HTTPS，HTTP 和免密限于本机回环地址。代理、重定向、URL 内凭据、查询参数和片段都在接入边界内拒绝或禁用。

会话、队列、子角色和自动化绑定选定的端点版本。地址或认证方式变化后桌面切换密钥分区，新连接需要重新配置凭据。旧会话续轮或审批接续会提示新建会话，旧队列保留可查看的失败原因，旧自动化需要重新保存并审核。历史仍显示原连接的名称和模型。正在执行的模型客户端使用启动时绑定的地址。

运行诊断记录配置的模型和供应商最后实际返回的执行模型，事件保留逐次结果。子运行按相同方式记录模型身份，模型与工具调用仍计入共享预算。流式失败保留已展示的增量及此前工具回执，未验证完的响应无法进入工具执行。缺少用量的响应显示为未知或仅显示已知部分。

参考 [百炼兼容接口](https://help.aliyun.com/en/model-studio/compatibility-of-openai-with-dashscope)、[工具调用](https://help.aliyun.com/en/model-studio/qwen-function-calling) 和 [流式输出](https://help.aliyun.com/en/model-studio/stream)。
