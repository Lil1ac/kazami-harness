# 工作台界面与实时对话

统一项目导航、聊天、任务、计划、子 Agent、文件、结果、诊断、运行队列与设置的布局和样式。视觉采用中性表面、单一强调色、紧凑列表和细分隔；侧栏底部的三段图标按钮直接切换浅色、深色与跟随系统，偏好只保存在当前浏览器，不改变运行配置。

## 信息结构

- 左侧按项目组织会话。底部的「运行队列」显示未结束数量和全局暂停状态，队列优先展示待处理、运行和排队事项。已结束的结果回到会话或自动化查看，未建立运行的失败和取消记录可在队列中展开。
- 对话显示用户消息、实时过程和最终回答。运行中的过程默认展开，结束后默认折叠。手动展开时暂停自动滚动，保留阅读位置。过程正文、思考文字与工具按发生顺序呈现，参数和原始回执按需展开。
- 每轮详情分为结果、输出、文件、工作和诊断。任务、计划、Agent 归入工作，待批准计划与动作由对话内的处理区统一承接。宽屏使用侧栏，窄屏使用抽屉。切换轮次保留输入草稿，续聊仍追加到最新轮。
- 从工具操作或本轮摘要可查看命令输出。标准输出和标准错误按宿主返回的字节位置读取。阅读长日志时可暂停跟随，从开头逐页查看或回到最新。界面分别说明退出码、模型预览截断和宿主捕获上限。
- 任务采用紧凑列表，详情包含范围、完成条件、依赖与真实证据。人工修改沿用版本校验，归档和历史隐藏写入入口。
- 项目会话分类直接使用文字标签切换，执行状态收进筛选菜单；仅显式进入多选后显示行复选框及批量操作，退出清空选择。
- 会话顶栏可以查找当前对话的提问和最终回答。回车查看下一处，Shift+回车查看上一处，Escape 回到查找按钮。返回来源列表时恢复原筛选、页码与滚动位置，分类标签可用方向键切换。
- 子 Agent 列表展示角色、任务和真实状态；详情承载报告、来源、分页原文及轨迹。停止单个子项仍由独立接口处理。
- 自动与先规划共用两项菜单，切换只影响下一次提交。计划批准、修改和拒绝仍绑定当前请求及版本。
- 发送区显示本次项目、执行位置、权限和模型。Git 项目的首轮可直接选择原目录或独立工作树，路径与基线展开查看。续轮显示会话固定的实际位置和继承的模型。
- 新建和普通续轮可从发送区引用 UTF-8 项目文件或行段。选择器按原目录、所选 Git 提交或会话工作树读取。发送时重新核对版本并固定引用，队列和模型使用固定内容。用户消息的文件标签可以打开本轮引用快照。
- 每轮最多引用 8 项，单项 32 KiB、合计 64 KiB，选段源文件最多读取 1 MiB。源文件在预览后变化时，发送会保留草稿并提示重新预览。实际模型请求继续按整体上下文预算核验。
- 待处理决定从会话顶栏或队列进入审阅抽屉。长计划的正文独立滚动，批准、修改和拒绝固定在底部。关闭抽屉清除查看参数并恢复焦点。
- 每轮交付摘要从固定快照读取文件数量和验收状态，打开该轮代码差异、验收证据或产物。点击文件定位其补丁，桌面可展开宽视图，窄屏全宽查看。文件页同时提供工作树处置与成果采纳入口。
- 运行控制与消息输入分开，用户可在执行时补充要求或排到下一轮。发送不确定、暂停、取消和错误按实际状态显示。
- 运行配置按默认值、模型服务、技能与集成、桌面分区。角色模型与预算按需展开，校验失败会打开出错的分类和字段。默认值和下载目录由同一份表单保存，浏览器的运行覆盖在刷新后清除。
- 「技能与集成」按技能、MCP、Hooks 分开显示目录。详情抽屉承载技能原文与附属资料、MCP 连接配置与工具定义，以及当前项目的 Hook 审核。导入、信任、发现和启用均有独立操作。项目设置中的 Hooks 使用同一套详情与审核入口。

## 流式数据链路

`DeepSeek SSE → StreamAssembler → RunContext.model_delta → events.jsonl → 运行 SSE → useRunEvents.timeline → TurnActivity`

模型请求统一使用流协议。首片立即发布，后续同通道文本按约 80ms 或累计 2KiB 合并，通道切换和结束时排空。`model_delta` 包含 `model_turn`、`channel`、`delta`；工具参数另含 `tool_index`、`call_id`、`name`。生成中的参数只供展示，完整响应及调用配对校验通过后才执行工具。

完整 `assistant_message` 覆盖同轮增量。宿主检查、可能的自动修复与收尾结束后，最终回答才固定展示；检查失败及后续修复过程均保留。内部历史压缩请求不进入用户文字流，供应商实际返回的思考文字在展开的执行过程中直接显示，以弱化文字区分，不增加第二层折叠。

原始诊断事件仍使用默认 400 条、最多 1000 条的窗口；对话另将文字累计成内容块，最多保留 1200 个块。长答复不会因原始增量被裁剪而丢失开头。历史展开按页补齐，内容块按最后事件序号去重；同轮终态刷新保留已有内容，断线不重放工具。未完成输出保留为前缀，不当作最终答复；已有输出后不透明重试模型请求。

## 团队协作

会话工作栏的“团队”显示稳定成员数；Agent 详情按成员查看任务、依赖版本、累计用量、消息和执行日志。发送指示只落盘，“发送并继续”才通过原队列请求负责人续轮。成员具体动作仍在父会话审批；此前审批段的证据标明实际执行编号。

全部有效成果汇集后，从团队整体成果进入候选检查、人工确认采纳和父目录复验；单成员补丁不能替代团队整体成果。历史使用当轮固定快照并关闭管理入口。停止、确认未知旧段及丢弃工作树均有明确确认，停止不自动删除成果。协议与验收见 [团队协作](TEAMS.md)。
