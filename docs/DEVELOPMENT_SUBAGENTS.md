# 写入型子 Agent 与成果集成（C07 + C13）

2026-11-04 按用户批准的 Plan 实施。本轮提供主 Agent 统一协调的隔离开发，不建立 Agent Teams、分布式执行或操作系统沙箱。工程、页面与真实模型验收分别记录，最终验收状态见本文末尾。

## 用户闭环

批准开发方案 → 主 Agent 创建有完成条件的工作项 → delegate_develop 隔离开发 → 查看子报告及固定差异 → 选择父工作区准备集成 → 解决冲突、检查候选并明确确认采纳 → 复验父目录 → 主 Agent 继续核对整体工作。

探索/审阅仍用 delegate_readonly；开发使用同一父级双槽额度、预算、等待、查询与取消协议。开发默认8次模型、20次工具、180秒，最多12/30/180，实际值受父剩余预算及收尾预留裁剪。子项不进入顶层队列，不递归委派，不自批操作，不自动提交、推送或创建 PR。

## 开发输入与权限

- delegate_develop 必须关联当前会话内可执行的 task_id，并提供明确 objective、非空 write_scope；工作项须有完成条件，依赖已满足、无其他开发者占用，当前计划最新版本已批准。
- write_scope 为仓库相对普通文件或目录前缀，拒绝绝对路径、父级穿越、通配符及控制目录。实际范围与父可写目录取交集，开发仍受宿主、会话和规划权限约束。
- 为完整固定代码起点，首版需要父级允许读取完整项目。没有 Git、链接/子模块、不支持的文件、超限或来源变化明确拒绝，不启动子模型。
- 开发角色可使用父级已开放的读取、写入、编辑与命令工具；无任务管理、记忆候选、规划决定、递归或新凭据来源。文件工具执行前约束范围；本机命令依照既有具体动作审批执行。
- 命令仍有当前系统用户的访问能力。文件范围和 Git 工作树不提供进程/网络沙箱；命令产生的实际成果在收尾和采纳阶段再次核对范围。

## 真实起点与成果

子工作树先建立 detached Git 检出，再覆盖父实际代码快照，包含受支持的已跟踪未提交修改、删除及非忽略未跟踪文件。忽略文件不复制，不隐式复制依赖或密钥。采集前后核对父目录、HEAD、索引与源码，变化则拒绝；原目录与真实索引不被修改。

起点保存为不可变 Git 树，不创建提交。子差异相对于该起点，避免把父已有修改作为子交付重复带入。解释器沿用已解析宿主入口，源码路径切换到子工作区；不自动安装依赖。准备失败或取消时仅尝试回收已验证属于本子项的未执行工作树，无法安全清理则保留路径及事件供核对。

结束后固定补丁、成果树、变更路径和报告。范围检查按不合并重命名的路径集合进行，重命名的删除来源和新增目标均受检查。超范围时标记 subagent_scope_violation，保留证据并禁止正常采纳；快照失败也不作为成功成果交付。

## 审批与逻辑接续

子文件/命令审批记录带原父编号、子编号、具体参数和输入指纹，归属于父会话。父运行进入 waiting_input 并显示子任务来源；活动开发未收拢前禁止父级切换或提交新计划。其他开发子项在模型/工具边界安全暂停，正在执行的动作先收拢，读取型子项可完成。等待释放顶层执行槽。

明确批准后建立新的父 Run，逻辑接续原子工作树与已配对历史，宿主先核验并执行保存的原动作，再交给子模型。原动作不再次消耗工具次数；同批其余预生成调用不恢复。父子分别扣除此前模型/工具/活动时间，子消费仍只向父计一次；人工等待不计入活动时间。

多个待审批子项逐次处理。保留兄弟原动作的不可变指纹，只有当前父快照明确指向且同会话时才能批准。拒绝/取消决定零模型、零工具；其他待审批项保持可处理。重启只读，不恢复旧协程、不自动重放；已开始结果不明从嵌套子回执对账，无法确认保持 unknown。

审批接续是专用检查点，不提供任意子上下文 resume、多模型切换或自动失联恢复。

## 集成、任务与清理

C13 接收父快照明确登记的开发子成果，仅提供所属父工作区作为目标；原目录和会话隔离工作树均受支持。后端核验来源归属、固定树、完整变更范围及父目录身份，不接受客户端任意路径。子成果使用各自稳定工作树流作为增量锚点，避免兄弟成果互相冒充上次基线。

准备、冲突处理、候选检查、人工确认、索引保护、写回、目标复验、重启对账和受保护撤销复用原 C13 队列及协议。父目录在预览后发生变化时原确认失效；单来源可串行采纳；互不重叠的已完成子成果可组成同一候选，统一通过整体验收后一次确认写回，避免前后端互相依赖时第一份成果无法单独通过检查。组合前核对所有固定来源及范围，同路径重叠明确阻止自动组合，需逐项审阅处理。来源报告或子命令输出不代替候选/目标检查。

工作项显示开发归属及最新采纳状态；子报告返回不自动完成任务。尚未采纳的开发成果不能以报告回执标记完成，已采纳后仍需完成说明和当前轮真实工具证据；项目检查结果独立展示。

开发报告可引用本子项实际成功的读取、写入、编辑及命令回执；只读报告仍仅接受读取证据。引用工具成功不代替独立项目验收。

子详情可明确丢弃已停止、无待审批/集成作业的子工作树，固定报告与补丁继续可读。彻底删除会话前必须先处理父及所有开发子工作树；已丢弃子工作树的元数据和成果文件随冻结清理清单一并删除，不残留独立目录。
